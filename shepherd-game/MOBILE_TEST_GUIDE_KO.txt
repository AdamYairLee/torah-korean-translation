Protect the Flock v2.3.4 모바일 그래픽·성능·화면·앱 설치 시험 안내
===================================================

1. 광고 회사 계정이 없어도 시험할 수 있습니다
-------------------------------------------------
- 이 버전의 GameDistribution gameId는 비어 있습니다.
- 일반 실행에서는 외부 광고 SDK를 내려받지 않으며 실제 광고도 전혀 나오지 않습니다.
- 모바일 조작, 가로 화면, 그래픽, 저장과 불러오기는 광고 연결과 무관하게 작동합니다.

2. 일반 모바일 시험
-------------------
- ZIP을 풀어 웹 서버에 올린 뒤 휴대폰 또는 태블릿 브라우저에서 여십시오.
- 한국어 바로 열기: index.html?lang=ko
- 영어 바로 열기: index.html?lang=en
- 히브리어 바로 열기: index.html?lang=he
- ZIP 파일이나 index.html을 휴대폰 파일 앱에서 직접 여는 방식은 브라우저 보안 때문에 3D 모듈이 실행되지 않을 수 있습니다. 반드시 http:// 또는 https:// 주소로 시험하십시오.

3. 광고 연결 위치만 시험하는 방법
----------------------------------
- 실제 광고 대신 내부 시험 화면을 사용하려면 주소 끝에 adtest=1을 붙이십시오.
- 예: index.html?lang=ko&adtest=1
- 내부 시험 화면은 약 2.2초간 표시되며 광고가 아닙니다.
- 표시되는 동안 게임·입력·소리가 멈추고, 사라진 뒤 다시 시작되는지를 확인할 수 있습니다.

시험 위치 A — 저장한 게임 다시 열기
1) 새 게임을 시작합니다.
2) 왼쪽 위 일시정지 버튼을 누르고 저장합니다.
3) 페이지를 새로 연 뒤 이어하기를 누릅니다.
4) 내부 광고 시험 화면이 끝난 다음 저장 위치에서 이어지는지 확인합니다.

시험 위치 B — 야영지 임무 성공
1) adtest=1 상태에서 야영지 임무를 성공합니다.
2) 성공 연출 뒤 내부 광고 시험 화면이 표시되는지 확인합니다.
3) 시험 모드에서는 이 위치를 쉽게 확인하도록 항상 표시됩니다.
4) 나중에 실제 광고가 연결되면 모바일에서만 성공 시 33% 확률로 요청합니다.

4. 가로 화면 확인
-----------------
- Android·일부 태블릿 브라우저에서는 전체 화면과 가로 잠금을 자동으로 요청합니다.
- iPhone/iPad Safari처럼 브라우저가 자동 회전 잠금을 허용하지 않는 경우에는 세로 화면에서 게임을 차단하고 가로로 돌리라는 안내를 표시합니다.
- 가로로 돌린 뒤 게임 화면과 조작 버튼이 나타나는지 확인하십시오.
- 일반 Chrome 탭 또는 사이트 미리보기 창에서는 게임을 누르기 전 브라우저 상단 막대가 남을 수 있습니다. v2.3.4는 이 막대를 제외한 실제 남은 높이를 측정해 시작 화면을 자동으로 가로형 2열로 바꿉니다.
- 새 게임·이어하기·언어 선택을 누르면 전체 화면을 요청합니다. 브라우저 정책상 전체 화면이 거부되어도 모든 시작 버튼과 캐릭터 선택 버튼은 짧은 가로 화면 안에 유지됩니다.
- 홈 화면에 설치한 앱으로 열면 처음부터 주소창 없는 전체 화면으로 실행됩니다.

5. 모바일 조작 확인
-------------------
- 왼쪽 아래 원형 조이스틱: 방향과 속도를 연속적으로 조절
- 오른쪽 빈 게임 화면 드래그: 시점 회전
- 오른쪽 아래 큰 버튼: 물매 길게 눌러 충전, 손을 떼어 발사 / 지팡이 사용
- 큰 버튼 위에서 시계 반대 방향: 무기 선택 → 시점 변경 → 달리기 → 양떼 부르기
- 왼쪽 위 석판 버튼: 일시정지
- 일시정지 메뉴: 언어, 소리, 계속, 저장, 게임 종료
- 모바일에는 마우스 감도 항목이 표시되지 않습니다.

6. 저장 확인
------------
- 진행 상태는 localStorage 기본 저장과 IndexedDB 보조 저장에 함께 기록됩니다.
- 저장 후 페이지를 닫았다 다시 열고 이어하기가 활성화되는지 확인하십시오.
- 시크릿/비공개 모드는 브라우저가 사이트 데이터를 지울 수 있으므로 장기 저장 시험에는 사용하지 않는 편이 좋습니다.

7. 홈 화면 앱 설치 확인
-----------------------
- 앱 설치 배너와 홈 화면 아이콘은 반드시 https:// 주소 또는 개발용 localhost 주소에서 시험하십시오.
- 파일 앱에서 index.html을 직접 열거나 일반 http:// 공개 주소로 열면 브라우저 보안상 앱 설치 기능이 작동하지 않습니다.
- 언어를 고른 뒤 시작 화면에서 전용 아이콘이 있는 설치 배너가 나타나는지 확인하십시오.
- Android Chrome: '앱으로 설치'를 누른 뒤 운영체제 설치 확인창에서 설치합니다.
- iPhone/iPad Safari: '앱으로 설치'를 누르고 표시되는 안내대로 공유 버튼 → 홈 화면에 추가를 선택합니다.
- 설치 후 홈 화면에 다비드와 양이 함께 있는 전용 아이콘이 표시되는지 확인하십시오.
- 홈 화면 아이콘으로 실행하면 브라우저 주소창 없이 전체 화면으로 열리고 가로 화면을 요청합니다.
- 홈 화면 아이콘으로 다시 열었을 때 설치 전 선택한 영어·한국어·히브리어 설정이 유지되는지 확인하십시오.
- 이미 설치한 앱으로 실행하거나 데스크톱으로 실행하면 설치 배너가 나오지 않습니다.
- '나중에'를 선택하면 7일 동안 배너를 다시 띄우지 않습니다.
- 시각 시험용 주소: index.html?lang=ko&installtest=1 (데스크톱에서도 배너 디자인 확인 가능)

8. 재실행 캐시 확인
-------------------
- 처음 접속한 뒤 게임에 실제로 사용된 모델·음원·이미지는 기기 캐시에 저장됩니다.
- 두 번째 실행부터 핵심 시작 파일과 사용한 자산을 재활용하여 로딩 중 불필요한 재다운로드를 줄입니다.
- 게임을 업데이트하면 v2.3.4 캐시 이름이 바뀌어 이전 핵심 파일과 섞이지 않도록 구성했습니다.
- 브라우저의 사이트 데이터나 앱 저장 공간을 지우면 캐시와 저장 게임이 함께 지워질 수 있으므로 주의하십시오.

9. 데스크톱 확인
---------------
- 데스크톱에서는 기존 키보드·마우스 조작만 표시됩니다.
- 게임 코드가 모바일 광고 요청을 데스크톱에서 즉시 건너뛰므로 두 위치 모두 광고가 나오지 않습니다.
- 데스크톱에서는 installtest=1을 붙이지 않는 한 앱 설치 배너가 표시되지 않습니다.

10. v2.3.4 로딩·그래픽·성능 확인
-------------------
- 모바일 새 게임 시작 시 필수 다비드 자료와 공용 양 모델만 먼저 준비합니다.
- 성전, 나무, 맹수, 강도, 경비병, 시민 모델은 첫 게임 화면 뒤에 한 종류씩 순서대로 준비합니다.
- 모바일에서는 동일한 외형과 애니메이션을 유지한 경량 3D 모델을 자동 선택하고, 데스크톱에서는 기존 원본 모델을 그대로 사용합니다.
- 모바일 내부 렌더링 선명도는 기기와 장면 부하에 따라 약 0.82~1.18 범위에서 조절됩니다. 이전판처럼 0.40~0.58까지 낮아지지 않습니다.
- 모바일은 안정적인 약 30FPS를 목표로 하며, 먼 나무·도시·동물은 화면에서 보이지 않을 때 렌더링과 애니메이션 갱신을 줄입니다.
- 큰 자산의 캐시 저장은 게임으로 전달되는 응답을 더 이상 막지 않습니다.
- 로딩 단계가 8% → 18% → 46% → 88% → 100%로 바뀌며 현재 작업 설명도 함께 표시됩니다.
- 그래픽 준비 응답이 늦어져도 모바일에서는 제한 시간 뒤 첫 화면으로 계속 진행합니다.
- 첫 화면 아래의 `토라웹으로 돌아가기`와 `Back to AI Korean` 버튼이 각각 토라웹 첫 화면과 AI Korean 페이지로 이동하는지 확인하십시오.
- 이전 버전을 설치한 상태에서 교체한 경우 새 파일을 커밋한 뒤 Chrome 탭을 완전히 닫고 다시 여십시오. 그래도 이전 화면이면 한 번 새로고침하면 v2.3.4 서비스 워커가 활성화됩니다.
