Jewish Korean 토라웹 업데이트 보고서

이번 업데이트는 사용자가 이번 대화에서 확정한 항목만 반영했습니다.
AI-Korean 폴더와 한글앱 코드는 수정하지 않았으며, 원본 ZIP과 해시를 비교해 동일함을 확인했습니다.
현재 사용 중인 한국어/히브리어 폰트와 style.css는 수정하지 않았습니다.

1. 메뉴 정리
- 기록 토라 메뉴에서 다음 항목의 노출만 제거:
  · 베레쉬트
  · 바미드바르
  · 드바림
- 기록 토라의 슈모트, 바이크라는 유지
- 구전 토라 > 미슈나에서 다음 다섯 질서 메뉴의 노출 제거:
  · 모에드
  · 나쉼
  · 네지킨
  · 코다쉼
  · 타하로트
- 제라임과 그 안의 기존 번역 자료는 유지
- 유대교 이모저모 메뉴 삭제
- 토라 강의, 노아하이드 강의, 유대교 용어 검색어, 검색창은 유지

2. 메인 메뉴 동작 개선
- 기록 토라, 토라 강의 등 펼침형 메뉴는 한 번에 하나의 계열만 열리도록 정리
- 다른 메뉴를 선택하거나 본문/노아하이드 강의를 열면 기존에 펼쳐진 하위 메뉴가 자동으로 닫힘
- 중첩 메뉴인 토라 강의 > 슈타인잘쯔 강의는 상위 메뉴를 유지한 채 정상적으로 열림

3. 슈타인잘쯔 토라 강의 파라샤 선택 버튼
- 다섯 책의 각 JSON 안에 사용자가 직접 적어 둔 title 텍스트를 읽어 버튼을 자동 생성
- 이름을 임의로 새로 작성하지 않음
- 화면 버튼에서는 공통 접두어인 “파라샤트”만 제거하고, 뒤의 명칭은 JSON 원문 그대로 유지
- 버튼을 누르면 해당 파라샤 구간만 표시
- 파라샤 목록 순서는 각 JSON에 작성된 순서를 그대로 따름

4. 노아하이드 강의 목차 페이지 구분
- 한 화면에 강의 목차를 최대 5개만 표시
- 전체 강의 수에 따라 [1], [2], [3] 형태의 페이지 버튼을 자동 생성
- 각 페이지에서 해당 목차를 누르면 기존처럼 본문이 표시됨
- 현재 선택된 강의와 현재 목차 페이지 상태를 유지

5. 수정한 핵심 파일
- index.html
- app.js
- TORAH_WEB_UPDATE_REPORT_KO.txt (신규 보고서)

6. 수정하지 않은 항목
- style.css 및 현재 폰트 설정
- AI-Korean 전체
- 토라/미슈나/강의 JSON 본문과 사용자가 적은 파라샤 제목
- 유대교 용어 검색어 페이지
- 검색 기능
- 토라 강의 본문
- 노아하이드 강의 본문
